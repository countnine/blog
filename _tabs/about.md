## countnine

개발하면서 배운 것들을 정리하고 공유합니다.

### 관심 있는 것

- Windows 데스크톱 애플리케이션 (WPF)
- 자동화와 셀프호스팅
- 개발 생산성 도구

### 만든 것

- **musebase** — Windows용 실시간 이중 언어 데스크톱 가사 오버레이
- **youSum** — YouTube 채널의 새 영상을 자동 요약해 RSS로 내보내는 서비스
